⚡ REST API Endpoints for Frontend UI

Full CORS enabled. Call these from React, Vue, Angular, or Vanilla JS:

1. Continuous Move (On Button Down):
fetch("/api/ptz/move", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ direction: "left", speed: 0.5, ip: "192.168.96.30", port: 8888 })
});
2. Stop Move (On Button Up):
fetch("/api/ptz/stop", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ ip: "192.168.96.30", port: 8888 })
});
3. Step Nudge (On Single Click):
fetch("/api/ptz/step", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ direction: "up", speed: 0.5, duration: 0.35, ip: "192.168.96.30", port: 8888 })
});
